# 관측 원문 — 시드 하나만 공개합니다

> ⚠️ **이 폴더의 `round1/S10.txt` 는 카카오뱅크 AI가 2026년 8월 17일에 낸 답변 원문입니다.**
> **금리·계산 결과·안내 경로가 들어 있고, 그중 일부는 틀렸습니다.**
> **현재 정보가 아니며, 어떤 판단의 근거로도 쓰지 마세요.**
> 정확한 정보는 카카오뱅크 앱과 공식 안내를 확인하세요.

## 왜 하나만 공개하나

관측은 204턴(추천 경로 144 + 골든셋 60), 원문 약 51만 자입니다.
**전량을 올리는 것은 인용이 아니라 재배포에 가깝다고 판단했습니다.** 선을 긋는 것은 내용이 아니라 분량입니다.

그런데 하나도 올리지 않으면 다른 문제가 생깁니다 — **채점기를 남이 돌려볼 수가 없습니다.**
「룰이 결정적이다」가 주장으로만 남고 확인할 방법이 없어집니다.

그래서 **시드 하나를 예시로 넣었습니다.**

## 왜 S10인가

리포트의 발견 ④가 나온 시드입니다. 표 안에서 `원금 + 이자 = 납부액`이 맞지 않는 것을
룰이 잡아낸 자리이고, 공시 범위 밖 금리도 함께 걸립니다. **한 파일로 채점기의 두 축을 다 보여줍니다.**

## 돌려보기

```bash
node tools/score.mjs 1
```

이 파일 하나만 있는 상태에서도 아래가 그대로 나옵니다.

```
표검산      1   S10      ← 표 안 덧셈 불일치
공시범위밖   9   S10      ← 공시 하한보다 낮은 예시 금리
기준일없음   1   S10
재탕 T2     1            ← 숫자만 다른 추천(파라미터 순열)
```

같은 입력이면 같은 결과가 나옵니다. 그게 룰 기반을 고른 이유입니다 (`docs/02-결정기록.md` D-02).

원문 대신 **룰이 잡은 자리 주변 발췌**를 공개본 JSON에 담았습니다 (원문의 6~16%).

- `data/scored-round1.public.json` · `data/scored-round2.public.json` · `data/scored-golden.public.json`
