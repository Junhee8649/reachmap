# 신청한 지 한참 지났는데 완료 알림톡이 왔어요 (알림 기준)

이렇게도 물어봐요: 왜 이제 와서 알림이 와? / 알림톡이 늦게 왔어 / 완료 알림은 언제 오는 거야?

알림은 두 종류이고 기준이 다릅니다.

- **개별 자동이체 성공/실패 알림** — 실시간 처리건을 제외하고 **푸시**로 안내합니다.
- **통합 자동이체 결과 안내** — 신청일자와 관계없이, **신청 기준으로 모든 자동이체 이동이 완료된 날**을 기준으로 **알림톡**을 발송합니다.

가져오기는 최대 6일(주말·공휴일 제외)이 걸릴 수 있어, 통합 안내는 마지막 건이 끝난 뒤에 도착합니다.
