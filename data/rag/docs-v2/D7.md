# 자동이체 가져오기가 안 돼요 (실패 사유)

이렇게도 물어봐요: 가져오기가 안 될 때 흔한 이유가 뭐야? / 왜 안 가져와져? / 가져오기 실패했는데 왜 그래?

아래와 같은 사유로 가져오기가 불가능할 수 있습니다.

- 가져오기를 **지원하지 않는 금융기관**의 자동이체인 경우
- **출금계좌 상태**가 이동 불가능한 상태인 경우
- 이미 변경·해지된 건인 경우
- **자동이체 출금일 당일**인 경우
- 자동이체를 **신규 신청한 당일 또는 1~2일 이내**인 경우
- 각 금융기관의 자동이체 정책 및 상품 유형이 가져올 수 없는 형태인 경우

메뉴 자체가 보이지 않는다면 「가져오기 메뉴에 접근이 안 됩니다」를 확인해 주세요.
